# 🌾 Harvest & Co.

**⚡ Scalable grocery commerce and inventory orchestration — built with Django.**

---

## 🧩 Architecture Overview
- **Backend**: Django 4.2 + Django REST Framework
- **Auth**: JWT-based secure authentication
- **Inventory**: Real-time stock tracking with atomic transactions
- **Database**: PostgreSQL for relational integrity

---

## 🚀 Why This Project?
Built to handle the complexities of modern grocery retail—dynamic pricing, perishable inventory, and seamless order fulfillment—all served through a robust, production-ready API.
